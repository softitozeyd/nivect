# VisionQC paneli

Bu klasör uygulamanın kullanılan React arayüzünü içerir. Backend ve kamera
servisi ile kurulum için [VisionQC rehberine](../README.md) bakın.

Geliştirme için Node.js 24 ile `npm ci`, `npm test` ve `npm run build:api`
çalıştırılabilir. API modu yerel VisionQC backend'iyle kullanılmalıdır.
